# Él es mi herman@

Prototipo web de acompañamiento entre pares para depresión, pérdida de pareja, duelo y adicciones.

## Abrir el prototipo

Abre `dist/index.html` en un navegador. Incluye bienvenida, cuestionario de cuatro pasos y sugerencias ilustrativas.

## Alcance

Los perfiles y grupos son ficticios. No hay autenticación, chat real ni almacenamiento de respuestas. No sustituye atención profesional ni servicios de emergencia.

## Archivos

- `dist/index.html`: interfaz.
- `dist/style.css`: diseño adaptable.
- `dist/app.js`: cuestionario e interacciones.
